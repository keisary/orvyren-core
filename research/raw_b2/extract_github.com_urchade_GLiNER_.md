# GLiNER: Generalist and Lightweight Model for Named Entity Recognition
[GLiNER Banner](https://github.com/urchade/GLiNER/blob/main/assets/banner.png)
GLiNER is a framework for training and deploying small Named Entity Recognition (NER) models with zero-shot capabilities. In addition to traditional NER, it supports incremental streaming NER, joint entity and relation extraction, and multi-task token classification.
