# docs/decisions/ — registre ADR

Toute décision future du projet est consignée ici au format **ADR** (contexte / options / décision / conséquences / date / statut), conformément au protocole de gel (`FREEZE_V2.md`, §I1).

Le paquet de gel **v1** est `FREEZE_V2.md` (racine). Les décisions qui le modifient créent un nouvel ADR daté — jamais une réécriture silencieuse.
