ORVYREN-Core, notre projet pour le FinTechathon de Shenzhen (thème F : agent wallet autonome). En une phrase : un moteur de décision financière qui prouve ce qu'il avance. Chaque chiffre est relié à sa source, chaque action est bornée par une politique, et l'agent ne détient aucune clé.

Le cas d'école : la chute de l'USDC pendant SVB (mars 2023). Trois sources, trois prix du même actif : 0,86 / 0,877 / 0,913. Tout se rejoue hors-ligne, à l'octet près. Du Python pur, sans dépendance.

Une revue externe est passée cette semaine : 18 findings, verdict 50/100 en l'état, 70-75 atteignable d'ici le 20. Les 4 défauts critiques de code sont déjà corrigés. La suite est à 147 tests.

Si vous voulez jeter un œil (ou essayer de casser la sécurité du truc) : le zip est en pièce jointe, tout est dedans, rien à installer. Le projet est expliqué dans orvyren-c-est-quoi.md et le digest de la revue dans revue-en-bref.md, les deux sont dans le zip.
